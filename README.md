# Supply My Classroom

A web application that helps teachers create and share classroom supply wishlists. Built with React and hosted on GitHub Pages.

## Features

- Browse classroom supply lists by teacher/grade
- Add items to wishlist with quantity control
- Share wishlists via social media or email
- Direct Amazon purchase integration
- Teacher registration system
- Mobile-responsive design

## Development

This is a static site using:
- React (via CDN)
- Vanilla CSS with modern features
- Local storage for data persistence

## Setup

1. Clone the repository:
```bash
git clone https://github.com/eric-wi/supply-my-classroom.git
cd supply-my-classroom
```

2. Open `index.html` in your browser or serve with a local HTTP server:
```bash
python3 -m http.server 8000
```

3. Visit `http://localhost:8000` in your browser
